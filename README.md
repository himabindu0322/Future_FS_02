# FUTURE_FS_02 – Client Lead Management System (Mini CRM)

This project is part of the **Future Interns Full Stack Web Development Internship**.

## Project Description
A simple CRM (Customer Relationship Management) system designed to manage client leads collected from a website contact form.

## Features
- Add new client leads
- View all leads
- Manage lead information
- Simple user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express

## Purpose
This project demonstrates CRUD operations, backend integration, and basic lead management functionality.
